Nothing leaves the node unread.

Security isn't a feature tier. It's the chassis the rest is built inside.

Hardware you can audit with your eyes.

The transparent enclosure is the point: an agent can see there is nothing extra inside. No second radio, no mystery module. What you see routed through the frost is the entire signal path.

S.01
END-TO-END, ALWAYS ON

AES-256-GCM with ephemeral per-call keys. Key material is generated and destroyed inside secure elements — it never exists in plaintext anywhere else.

S.02
HARDWARE-ISOLATED VOICE PATH

A dedicated DSP owns the microphones. No host OS, no shared baseband, no software stack to subpoena.

S.03
ZERO-RETENTION ARCHITECTURE

Calls live in volatile memory and die with it. There is no cloud copy, because there is no cloud.

S.04
REMOTE KILL SWITCH

One signed command deregisters the SIM and shreds all key material in under three seconds.
